# Pocket Finance

**[⬇️ Download do APK](https://drive.google.com/file/d/1iFKaF_4ZFmOfk6j4sUg1rN8g14GaMXFj/view?usp=drive_link)**

Um aplicativo de controle financeiro pessoal desenvolvido em **Flutter**, pensado para facilitar o registro e o acompanhamento das finanças do dia a dia.

O Pocket Finance permite organizar receitas e despesas, acompanhar o saldo, visualizar o histórico de transações e analisar os gastos de forma simples e visual.

## Funcionalidades

* Cadastro de **receitas e despesas**
*  Organização das transações por **categorias**
*  Visualização do **saldo total**
*  Histórico completo de transações
*  Categorias com **ícones e cores personalizadas**
*  Exclusão de transações
*  Armazenamento dos dados localmente
*  Interface desenvolvida para uma experiência simples e intuitiva

## Tecnologias utilizadas

* **Flutter**
* **Dart**
* **GetX** — gerenciamento de estado
* **SQLite / sqflite** — armazenamento local
* **fl_chart** — visualização de dados
* **Material 3** — interface

## Estrutura do aplicativo

O aplicativo é organizado em diferentes telas para facilitar a navegação:

* **Início** — resumo financeiro e saldo
* **Nova transação** — cadastro de receitas e despesas
* **Transações** — histórico e filtros
* **Estatísticas** — análise dos dados financeiros
* **Categorias** — organização das categorias
* **Configurações** — opções do aplicativo

## Interface

O Pocket Finance utiliza uma interface baseada no **Material 3**, com foco em uma experiência limpa, organizada e fácil de utilizar.

A identidade visual utiliza tons suaves e uma combinação de verde e azul para representar organização, equilíbrio e controle financeiro.

## Banco de dados

As transações são armazenadas localmente utilizando **SQLite**.

Dessa forma, os dados podem ser consultados e utilizados para calcular o saldo e gerar os gráficos do aplicativo.
